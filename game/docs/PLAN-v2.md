# Forest Trail 第二版开发计划

目标：在第一版（松溪环线，单车，白天）的基础上，把画面、车辆、场景、声音、界面和展示能力做一次系统升级。本文件是执行计划，完成情况写在 `VERIFICATION.md`，取舍写在 `DESIGN.md`。

## 0. 基线与框架

- 先确认 `npm run build`、`test:proving`、`test:lap` 在改动前全部通过，作为回归基线。
- 把车辆参数从单个全局 `VEHICLE` 改为 `VehicleSpec` 列表：物理（质量、轴距、轮距、轮胎、悬挂、动力、转向、碰撞盒）和外观（模型名、车漆、挂点、灯位）分开，物理、视图、音频、试验场都按所选车辆读取。
- Blender 车辆脚本拆成共享零件库（车轮、整体桥、弹簧减震、传动轴、灯具）和每辆车一个车身脚本。每辆车导出 `vehicle_<id>.glb` 和 `vehicle_<id>.json`（悬挂挂点、灯位），游戏按 JSON 装配，不再在代码里写死坐标。

## 1. 车辆

| 车辆 | 风格 | 参数取向 |
| --- | --- | --- |
| 老松 Scout（现有车升级） | 短轴方正复古四驱，赭红 | 均衡：基准手感保持第一版验收结果 |
| TOYOTA Land Cruiser 60 旅行车（新） | 按 `车辆正面_白天/黑夜.png`：圆灯、TOYOTA 格栅字、琥珀转向灯、钢保险杠带绞盘和雾灯、右侧通气管、全长行李架 | 长轴、重、宽：更稳、扭矩大、转弯半径大 |
| 溪谷 Ranger 小皮卡（新） | 复古小皮卡，双色漆，货斗装露营装备 | 轻、快、悬挂软：高档更快，低档扭矩和离地间隙较小 |

- 修复现有车前悬挂穿模：在 Blender 里渲染满行程（压缩、伸长、左右交叉）和满舵状态逐一检查，调整车架、弹簧塔和桥的相对位置。
- 细节：钣金缝、铰链、门把手、雨刷、雨槽、窗框胶条、后视镜、牌照、拖钩、泥挡、脱困板、铲子、千斤顶、后梯、车顶行李、内饰座椅和仪表台、减震器、横拉杆、防倾杆、胎侧和胎肩花纹、不同风格的轮毂。
- 车身泥污：车漆材质按行驶里程和泥地累积脏污，洗车（涉水）会冲掉一部分。
- 进游戏前选车：标题页有选车界面（车辆转台展示、参数条、车漆），所选车辆写入存档。

## 2. 灯光与昼夜

- 白天 / 夜晚两种模式，标题页和暂停菜单都能切换；演示模式里做平滑过渡。
- 夜晚：星空与月亮天空盒、月光方向光、夜间雾色和曝光、营地篝火（闪烁点光源）、串灯、小屋和船屋窗户发光、萤火虫。
- 车灯：L 开关大灯，B 切换远 / 近光。近光下压、射程短、光斑宽；远光射程远、更亮；Scout 远光联动车顶灯排，Toyota 带雾灯。尾灯、刹车灯、倒车灯随驾驶状态变化。灯罩自发光、光晕和雾中光锥。

## 3. 地形与场景

- 颠簸路面：
  - 炮弹坑群；
  - 交叉轴（对角起伏，让对角车轮悬空）；
  - 搓板路；
  - 原木台阶；
  - 岩石花园；
  - 侧倾坡；
  - 陡坡。
  - 这些都是真实的地形高度或碰撞体，不是贴图。
- 新区域：
  - **越野训练场**（营地南侧），集中布置上面的障碍。有起终点门、分段计时和最佳成绩，是一个新的可选玩法。
  - **赤岩峡谷**，参考 steam-05/11/13：层叠砂岩崖壁，木板吊桥过干沟，桥可以开车通过。
  - **秋色林**，参考 steam-01/10：红枫、白桦、金色落叶松、金色高草甸，另有红色 A 字木屋。
  - **湖畔船屋**，参考 steam-09：高脚船屋、长栈桥、小船、路灯。
  - **营地夜景**，参考 steam-02：露营拖车、串灯、提灯。
  - **巨石坡**，参考 steam-14/06：岩阶近路两侧的大块巨石。
- 现有场景提升：
  - 远山改为有光照和积雪的立体山体；
  - 北侧山坡加瀑布；
  - 植被加风动；
  - 草更密、更有层次；
  - 土路加龟裂纹理；
  - 路边加野花；
  - 加入野生动物：鹿群在草甸吃草，车靠近时跑开；鹰在空中盘旋。
- 主环线沿途也加入一些坑洼和搓板路段。所有路段都要保证自动驾驶和各车型能通过，试验场回归不退化。

## 4. 音乐

- 使用网上可再分发的免费曲目（优先 CC0，其次 CC BY 并署名），分白天、夜晚、演示几组曲目，交叉淡入淡出。
- 曲目、作者和许可证写进游戏内的“制作名单”和 `docs/CREDITS.md`。音量受“氛围音乐”滑条控制，暂停时压低。

## 5. 界面

- 统一的现代视觉：半透明磨砂面板、圆角、细线图标（内联 SVG）、清晰的层级和动效。
- 覆盖范围：
  - 加载页；
  - 标题页：选车、昼夜、开始 / 继续、演示；
  - HUD：环形速度表、档位、灯光和四驱状态、罗盘、目标卡片、训练场计时；
  - 暂停菜单：侧栏导航；
  - 地图；
  - 提示；
  - 旅程手账；
  - 制作名单。

## 6. 演示模式与封面

- 一键录制：标题页“录制演示视频”。进入约 2 分钟的导演模式，按镜头表自动驾驶和运镜，展示：
  - 三辆车；
  - 车辆细节特写；
  - 颠簸路面和交叉轴；
  - 泥地和绞盘；
  - 涉水；
  - 峡谷吊桥；
  - 秋色林；
  - 白天转夜晚、开大灯、远近光。
- 运镜使用平滑样条：推、拉、摇、跟拍、升降、环绕、低角度。画面配字幕卡。
- 用 `MediaRecorder` 同时录制画面和游戏音频，结束后自动下载 WebM。另提供只播放、不录制的入口。
- 实际录一遍，产出 `docs/demo.webm` 和 `docs/demo.mp4`。
- 游戏封面：3:2 竖屏，1200×1800。在游戏内用封面镜头渲染，再叠加标题排版，导出为 `docs/cover.png`，同时放一份到 `public/cover.png`。
